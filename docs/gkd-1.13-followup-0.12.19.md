# GKD 1.13 跟进：NoAdMi 0.12.19-preview / 104

2026-11-08，基于原0.12.18-r2提交9142b6a开发，预发布见[0.12.19-preview](https://github.com/tiancaiProgramer/NoAdMi/releases/tag/v0.12.19-preview)。官方稳定版为[1.13.0](https://github.com/gkd-kit/gkd/releases/tag/v1.13.0)，固定提交`0ee5d146a382d1066cddfdb6d0ace9d9563a8464`（11月6日发布）。

| 项目 | 本轮结果 |
| --- | --- |
| 选择器 | commonMain/JVM共39个生产文件按官方原文更新，含查询/追踪一致性、关系位置与快速查询过滤；SOURCE.json保存哈希 |
| 全局规则范围 | 只有组级apps可显式纳入应用；子规则apps只覆盖页面/版本，不能绕过组级应用/系统/桌面范围；两类白名单和用户关闭状态保持 |
| 节点vid | 仅从节点自身包名下的资源ID生成；android:id、其他包及畸形ID不冒充相对ID |
| 无障碍滑动 | 100ms分段延续同一触点，页面/开关/规则失效后补最终UP；等待平台回调再释放输入通道，释放被拒则暂停至服务重连 |
| 匹配诊断 | 每2秒最多采样一次、每轮64个事件，记录短路/比较/候选等计数；不额外读取或保存屏幕文字、节点、值或选择器原文 |

订阅解析器/模型继续固定fe6736f；本轮对齐其组级范围语义，不为更新而改写用户订阅、等待、冷却、输入选择或既有设置。

GKD新独立Root/ADB/手动启动特权服务、伴生无障碍、快照/HTTP、自更新安装、完整统计/规则编辑界面未整体搬入。现有Root/Shizuku方式和特权输入保持；100ms分段取消仅适用于无障碍滑动，不宣称特权输入也支持该取消路径。

完整构建通过：13组Kotlin回归、414项实际Android节点适配代码的JVM替身检查、27组Java回归；新增范围21项、滑动48项、选择器/诊断57项和vid6项。滑动测试模拟真实回调顺序、拒绝、取消、重复回调及静止段时长，不替代Android实际触摸验收。

原签名v2/v3安装包位于`dist/NoAdMi-0.12.19-preview.apk`，已覆盖安装到MIX Fold 3 / Android 16，code104；拉回手机APK的SHA256与构建一致。发布包沿用该已安装APK。

8组隔离实测通过，触摸数据来自独立测试页面实际收到的MotionEvent：

| --- | --- |

| 关闭总开关 | 约0.207秒抬起，失效记录 |

通过样本使用350ms夹具matchDelay使页面稳定，不改用户规则。初始无等待样本在Activity信息补全时发生失效取消和重试，出现两对DOWN/UP；该失败保留，不计为单次连续成功。表中全部时长从实际DOWN计至UP/CANCEL，不是关闭开关后的响应时间，也不能作为广告跳过延迟。

测试暂用Root控制与无障碍输入，结束后13个原始配置/订阅/记录文件由新进程核对哈希一致；已恢复原Shizuku选项、菜单状态及服务列表，删除临时规则、测试记录、手机备份缓存和测试工具。普通NoAdMi无障碍与原有其他服务均连接。恢复时Shizuku控制进程回连超时，经原Root授权恢复普通无障碍后切回原Shizuku；增强连接最后仍显示连接中，尚未确认正常，未重启全局Shizuku。

锁屏/熄屏、服务中断、释放拒绝后的恢复、子规则页面/版本覆盖、更多白名单组合和第三方广告/功耗仍待验收；不据此宣称与GKD整体效果一致。历史成功和失败记录继续保留。详见 [实机摘要](../diagnostics/gkd-compat/gkd-1.13-device-0.12.19.json)。
